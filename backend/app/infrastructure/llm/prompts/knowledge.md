# KNOWLEDGE BLOCK

## 월령별 권장 수면 시간 (AAP)
0~3개월:14~17h / 4~11개월:12~15h / 12~23개월:11~14h / 24~35개월:10~13h
→ 1시간+ 부족: "수면량 주의" / 범위 이상: "안정적" 또는 "충분한 수면"

## 낮잠 전환
3~4개월(3→2회) / 12~18개월(2→1회) / 30~36개월(1→0회)
→ 전환기 수면 분절은 자연스러운 현상. 낮잠 감소 시 밤잠 증가하면 정상 수면 성숙.

## 수면 퇴행
4개월(수면 사이클 성인형 전환) / 8~10개월(기기·서기, 분리불안) / 12개월(걷기, 낮잠 전환) / 18개월(언어 급성장, 분리불안 2차) / 24개월(상상력, 취침 거부)
→ 퇴행 시 기존 수면 교육법 일관 유지. 2~6주 내 회복.

## 분리불안
8~9개월(영속성 개념 발달) / 18개월(언어·인지 격차)
→ 일관된 취침 루틴과 굿나잇 루틴 강조. 부모 일관성이 핵심.

## 취침 권장 시간대
0~3개월: 수유 패턴 우선 / 4~8개월: 18~20시 / 9~23개월: 19~20:30 / 24개월+: 19:30~21시
→ 9시 이후 취침은 Overtired 위험. 징후: 눈 비비기·귀 당기기·과잉 흥분·갑작스러운 울음.

## 월령별 정상 호흡수 (수면 중, 회/분)
0~3개월:30~55 / 3~6개월:25~50 / 6~12개월:20~40 / 12~24개월:20~35 / 24개월+:20~30
→ 정상: "안정적인 호흡 패턴" / 초과: "빠른 호흡, 수면 환경 점검 권장" / 미만: "느린 호흡, 소아과 상담 권장". 진단 표현 절대 금지.

## 수면 중 뒤척임
20분↓: 안정 / 20~40분: 보통 / 40분↑: 수면 분절 가능성, 환경 점검 권장

## 실내 환경 기준
온도: 18~22°C (신생아 20~22°C). 15°C↓ 또는 24°C↑시 수면 환경 점검.
소음: 50dB↓ 권장. 60dB↑시 수면 분절 가능성.
습도: 40~60%. 40%↓ 건조(호흡기 자극). 60%↑ 불쾌감·곰팡이.
조도: 5lux↓ 권장(멜라토닌). 낮잠 20lux↓. 높을수록 수면 질↓.

## 수면 교육법
퍼버법: 개입 낮음, 점진적 반응 늘리기, 빠른 독립 수면
의자법: 개입 낮음, 의자 점점 멀리 이동
쉬닥법: 개입 중간, 토닥이며 "쉬-" 소리, 점진적 개입 감소
안눈법: 개입 높음, 울음 최소화·즉각 반응, 독립 수면까지 오래 걸림
픽업앤다운: 개입 중~높음, 울면 안고 진정 후 내려놓기, 전환기에 적합
EASY 루틴: 먹기-놀기-자기 규칙, 전 월령
자장가 루틴: 일관된 취침 신호 형성, 전 월령
→ 뒤척임 40분↑ 또는 수면 부족: 수면 교육법 추천. 안정적: 현재 루틴 유지.
