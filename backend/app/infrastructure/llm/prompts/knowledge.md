# KNOWLEDGE BLOCK

## 수면 퇴행 — 시기별 원인과 대처
가장 자주 쓰이는 진단 기준. 갑작스러운 수면 악화 + 아래 월령 일치 시 퇴행으로 해석.

**4개월 (가장 중요, 영구적 변화):**
- 원인: 수면 구조 자체가 신생아형 → 성인형으로 영구 전환. 이전으로 돌아가지 않음.
- 특징: 사이클 전환 시 완전 각성, 잠들기 어려움, 낮잠 짧아짐
- 대처: 이 시기부터 Drowsy But Awake 연습 시작 권장. Sleep Prop 새로 만들지 않기.
- 지속: 2~6주. 이 시기 잘 넘기면 이후 수면 교육 훨씬 수월.

**8~10개월:**
- 원인: 기기·서기 등 대운동 발달 + 분리불안(영속성 개념 발달) 동시 폭발
- 특징: 이미 수면 교육된 아기도 야간 각성 증가, 취침 거부
- 대처: 기존 루틴 흔들지 않기. 낮 동안 충분한 신체 활동. 취침 루틴에 작별 인사 추가.
- 주의: 분리수면 처음 시작하기 가장 어려운 시기. 이미 시도 중이면 일관성 유지 강조.

**12개월:**
- 원인: 걷기 시작, 낮잠 2회→1회 전환기
- 특징: 낮잠 거부, 밤잠 분절
- 대처: 낮잠 전환 중이면 오전 낮잠을 오후 1~2시로 통합. 취침 시간 30분 당기기.

**18개월:**
- 원인: 언어 폭발기. 독립심↑ vs 의존 욕구↑ 충돌. 상상력 발달로 취침 거부 시작.
- 특징: "싫어" 반복, 취침 거부, 조기 기상
- 대처: 루틴에 선택권 부여 ("이 책 읽을까, 저 책 읽을까?"). 취침 시간 일관성 최우선.

**24개월:**
- 원인: 상상력 발달, 악몽 시작 가능, 형제 출생 등 환경 변화
- 대처: 취침 전 안심 루틴(작은 불빛 허용 등). 낮 동안 변화에 대한 충분한 대화.

→ 퇴행 중 새로운 수면 교육 시작은 비권장. 기존 루틴 유지가 빠른 회복의 핵심.
→ 퇴행 여부: 이전 주 대비 갑작스러운 수면 악화 + 위 월령 일치 시 퇴행으로 해석.

## 원더윅스 (Wonder Weeks — 정신적 도약기)
입력 데이터에 `원더윅스 해당: true`가 있을 때 참고.
- 정의: 인지 발달 도약 직전 일시적 퇴행 (보채기·수면 분절·분리불안↑). 보통 1~3주 지속 후 자연 회복.
- 특징: 도약 후 아기가 새로운 인지 능력(사물 영속성, 인과관계 등)을 획득함
- 대처: 루틴 유지 최우선. "지금 뇌가 자라고 있는 것"으로 부모에게 안심시키기.
→ age_kick에 도약 내용 간략히 + "2~3주 내 자연스럽게 회복돼요" 포함.

## 월령별 권장 수면 시간 (AAP)
0~3개월: 14~17h / 4~11개월: 12~15h / 12~23개월: 11~14h / 24~35개월: 10~13h
→ 1시간+ 부족: "수면량 주의" / 범위 이상: "안정적" 또는 "충분한 수면"
→ 낮잠 포함 합산 기준. 밤잠만 짧아도 낮잠이 충분하면 총량 먼저 확인.

## 각성 창 (Wake Window) — 재우기 타이밍의 핵심
아기가 깨어 있을 수 있는 최대 시간. 초과 시 Overtired → 코르티솔 분비 → 오히려 재우기 어려워짐.
0~1개월: 45~60분 / 2~3개월: 60~90분 / 4~5개월: 90~120분
6~8개월: 2~3시간 / 9~12개월: 3~4시간 / 12~18개월: 4~6시간

Overtired 징후: 눈 비비기, 귀 당기기, 과잉 흥분, 갑작스러운 울음, 멍하게 쳐다보기
→ 징후 나타나면 즉시 수면 루틴 시작. 취침이 권장보다 늦고 각성 많으면 각성 창 초과 의심.
→ 일별 데이터에서 전날 마지막 수면~당일 취침 간격이 길고 그날 각성 많으면 반드시 언급.

## 취침 권장 시간대
0~3개월: 수유 패턴 우선 / 4~8개월: 18~20시 / 9~23개월: 19~20:30 / 24개월+: 19:30~21시
→ 21시 이후 취침은 Overtired 위험. 평균 취침이 권장보다 늦으면 반드시 언급.
→ "더 피곤하면 더 잘 잔다"는 오해 → 실제로는 Overtired 시 코르티솔로 더 안 잠.

## 수면 보조 도구 (Sleep Prop)
아기가 잠들기 위해 반드시 필요로 하는 외부 조건. 수면 사이클 전환마다 같은 조건 요구 → 잦은 야간 각성의 주원인.

문제가 되는 Props:
- 젖/우유 빨며 잠들기 → 수유=수면 연상 형성
- 안겨서 완전히 잠든 뒤 눕히기
- 취침 시마다 쪽쪽이 삽입 (스스로 못 찾는 경우)
- 흔들거나 토닥여야 잠드는 경우

괜찮은 Props: 백색소음, 어두운 환경, 수면 인형(6개월+), 일관된 취침 루틴

→ 뒤척임 40분↑이나 야간 각성 반복 + 환경 양호한 경우 → Sleep Prop 형성 의심
→ 해결: Drowsy But Awake 원칙 + 수면 교육법 병행 제안
→ 표현: "잠드는 방식에 특정 도움이 필요한 습관이 형성됐을 수 있어요" (진단 표현 금지)

## Drowsy But Awake (졸리지만 깨어 있을 때)
수면 독립의 핵심 원칙. 아기를 완전히 재운 뒤 눕히면 수면 보조 도구 의존이 형성됨.
→ 졸음 신호(눈 비비기, 하품, 시선 흐릿) 나타난 직후 → 아직 눈 뜬 상태로 눕히기
→ 이 원칙이 지켜지면 수면 사이클 전환 시 스스로 재잠드는 능력 발달
→ 적용 가능 시기: 생후 4개월 이후 (이전은 수유 후 재우기 우선)

## 분리수면 시작 기준
- 3개월 이하: 비권장 (생체 리듬 미발달, 야간 수유 필수)
- 4~5개월: 준비 가능 시점 (생체 리듬 발달 시작, 4개월 퇴행 이후)
- 6개월+: 일반 권장 시점 (야간 수유 없이 수면 가능 체중 도달)
- 9개월 이후 첫 시작: 분리불안 심화로 난이도 높아짐 (불가능은 아님, 더 천천히)

준비도 확인:
- 수유 없이 2~3시간 수면 가능한가
- 4개월 수면 퇴행 이후인가 (수면 구조 성인형 전환 완료)
- Sleep Prop 의존이 있는가 (있으면 먼저 개선 후 시도 권장)

한국 문화 맥락 (부모 불안 해소용):
- 분리수면이 애착을 해친다는 연구적 근거 없음 (Gradisar 2016, 5년 추적 연구)
- 오히려 부모 수면 개선 → 낮 동안 반응성 향상 → 애착 안정에 기여
- "냉정한 육아"가 아니라 "아이 수면 독립을 돕는 과정"으로 표현할 것
→ leave_count↑ 또는 야간 취침 지연 데이터 있으면 응원 + 구체적 팁 제공

## 분리불안과 취침 루틴
8~9개월(영속성 개념 발달) / 18개월(언어·인지 격차 시기)
→ 이 시기 leave_count↑ 또는 취침 거부 패턴이면 분리불안 가능성 언급.

대처 루틴:
1. 굿나잇 루틴 일관화: 매일 같은 순서 (목욕→수유→자장가→굿나잇 인사→소등)
2. "곧 돌아올게" 예고: 방을 나갈 때 짧고 명확하게 고지. 몰래 나가지 않기.
3. 피크어부(까꿍 놀이): 낮 동안 반복해 "엄마는 사라져도 돌아온다"는 영속성 강화
4. 취침 전 충분한 낮 접촉: 낮 동안 애착 욕구 충족 → 취침 시 분리 저항↓

## 취침 루틴 구성 (20~30분)
권장 순서: 목욕(선택) → 마사지/로션 → 수유(잠들기 20~30분 전 완료) → 조명 어둡게 → 자장가/책 읽기 → Drowsy But Awake 상태로 눕히기
→ 루틴 일관성이 단일 최강의 수면 개선 요소
→ 수유 직후 재우기는 Sleep Prop 형성 위험 — 수유 후 20~30분 깨어 있는 시간 확보 권장

## 낮잠 전환
3~4개월(3→2회) / 12~18개월(2→1회) / 30~36개월(1→0회)
→ 전환기 수면 분절은 자연스러운 현상. 낮잠 감소 시 밤잠 증가하면 정상 수면 성숙.
→ 전환기에는 취침 시간을 30분 당겨 Overtired 방지.

## 수면 교육법 — 권장 월령 및 특징
**쉬닥법 (Shush-Pat):** 0~4개월 최적. 등 토닥이며 "쉬-" 소리. 안아 올리지 않음. 4개월 이후엔 오히려 자극이 될 수 있음.
**픽업앤다운 (PUPD):** 3~6개월. 울면 안아 진정 후 눕히기 반복. 7개월↑ 역효과 가능. 부모 체력 소모 큼.
**쉬닥법 + 손 올리기:** 4~6개월. 침대 옆에서 손을 등에 얹어 안심. 개입을 점진적으로 줄임.
**퍼버법 (Ferber):** 6개월+. 눕히고 방을 나감. 3분→5분→10분 간격으로 체크인(안아 올리지 않음). 보통 3~7일 내 효과. 일관성이 핵심.
**의자법 (Chair):** 6개월+. 의자를 침대 옆→방 중간→문 앞→방 밖으로 매 2~3일마다 이동. 2~3주 소요. 분리불안 심한 아기에 적합.
**EASY 루틴:** 전 월령. 먹기(Eat)→놀기(Activity)→자기(Sleep)→부모 시간(You). 수유=수면 연상 차단.

→ sleep_guide 선택 기준:
  - 3개월 이하: sleep_guide는 null (수면 교육 비권장)
  - 4~5개월: 쉬닥법 또는 픽업앤다운
  - 6개월+: 퍼버법 또는 의자법 (뒤척임·각성 많을 때), 환경 개선만으로 충분하면 EASY 루틴
  - 분리불안 심한 시기(8~10개월, 18개월): 의자법 우선 고려
  - Sleep Prop이 있는 경우: 어떤 방법이든 Drowsy But Awake 원칙 병행 필수

→ 뒤척임 40분↑ 또는 수면 부족 + Sleep Prop 의심: 수면 교육법 추천
→ 안정적이고 환경 양호: 현재 루틴 유지 + 긍정 강화

## 수면 중 뒤척임
20분↓: 안정 / 20~40분: 보통 / 40분↑: 수면 분절 가능성, 환경 및 Sleep Prop 점검 권장

## 실내 환경 기준
온도: 18~22°C (신생아 20~22°C). 22°C↑는 권장 범위 초과 [⚠ 표기]. 24°C↑는 수면에 직접 영향 — 조치 권장.
소음: 50dB↓ 권장. 50dB↑ [⚠ 표기]. 60dB↑ 시 수면 분절 가능성. 백색소음은 50~60dB 권장.
습도: 40~60%. 40%↓ [⚠건조 — 호흡기 자극]. 60%↑ [⚠과습 — 불쾌감·곰팡이].
조도: 5lux↓ 권장(멜라토닌 분비). 낮잠 20lux↓. 5lux↑ [⚠ 표기].

## 월령별 정상 호흡수 (수면 중, 회/분)
0~3개월: 30~55 / 3~6개월: 25~50 / 6~12개월: 20~40 / 12~24개월: 20~35 / 24개월+: 20~30
→ 정상: "안정적인 호흡 패턴" / 초과: "빠른 호흡, 수면 환경 점검 권장" / 미만: "느린 호흡, 소아과 상담 권장"
→ 진단 표현 절대 금지. 호흡 이상 + 체온 이상 동시 발생 시 소아과 상담 반드시 권장.
