## 월령별 권장 수면 시간 (AAP 기준)

| 월령 | 권장 수면 시간 |
|------|--------------|
| 0~3개월 | 14~17시간 |
| 4~11개월 | 12~15시간 |
| 12~23개월 | 11~14시간 |
| 24~35개월 | 10~13시간 |

→ 권장 범위보다 1시간 이상 부족하면 "수면량 주의" 언급.
→ 권장 범위 이상이면 "안정적" 또는 "충분한 수면" 표현 사용.

---

## 월령별 정상 호흡수 (수면 중, 회/분)

| 월령 | 정상 범위 |
|------|----------|
| 0~3개월 | 30~55회/분 |
| 3~6개월 | 25~50회/분 |
| 6~12개월 | 20~40회/분 |
| 12~24개월 | 20~35회/분 |
| 24개월 이상 | 20~30회/분 |

→ 평균 호흡수가 정상 범위 내: "안정적인 호흡 패턴" 표현.
→ 평균 호흡수가 정상 범위 초과: "빠른 호흡이 관찰됨, 수면 환경 점검 권장" 수준으로 작성.
→ 의학적 진단 표현 절대 금지 (예: "무호흡증", "호흡 장애" 등).

## 체온 판정 기준 (수면 중 최고 체온 기준)

| 최고 체온 | 상태 | 권고 |
|----------|------|------|
| 37.4°C 이하 | 정상 | 별도 언급 불필요 |
| 37.5~37.9°C | 미열 주의 | 수면 환경 온도·보온 확인 권장 |
| 38.0°C 이상 | 발열 의심 | 소아과 상담 권장 명시 |

---

## 수면 중 뒤척임 해석

| 뒤척임 시간 | 해석 |
|------------|------|
| 20분 이하 | 안정적인 수면 |
| 20~40분 | 보통 수준 |
| 40분 초과 | 수면 분절 가능성, 환경 점검 권장 |

---

## 실내 환경 기준

- 권장 실내 온도: 18~22°C (신생아: 20~22°C)
- 권장 소음 수준: 50dB 이하 (60dB 이상이면 수면 분절 가능성 언급)

## 수면 교육법 정의

| 교육법 | 부모 개입 | 특징 |
|--------|---------|------|
| 퍼버법 (Ferber) | 낮음 | 점진적으로 반응 시간 늘리기. 울음 일정 시간 허용. 빠른 독립 수면 목표. |
| 의자법 | 낮음 | 의자를 점점 멀리 이동. |
| 쉬닥법 (Shush-Pat) | 중간 | 옆에서 토닥이며 "쉬-" 소리. 안정 후 점진적 개입 감소. |
| 안눈법 (No Tears) | 높음 | 울음 최소화, 즉각 반응. 민감한 아기/부모에 적합. 수면 독립까지 오래 걸림. |
| 픽업앤다운 | 중간~높음 | 울면 안고 진정 후 내려놓기 반복. 중간 단계 전환기에 적합. |
| EASY 루틴 | 중간 | 먹기-놀기-자기 규칙적 루틴. 전 월령 가능. |
| 자장가 루틴 | 중간 | 일관된 취침 신호 형성. 전 월령 가능. |

→ 뒤척임 40분 초과 또는 수면 부족: 수면 교육법 추천.
→ 안정적인 경우: 현재 루틴 유지 방법 제안.

## 원더윅스 기준 월령

원더윅스(발달 급성장기)가 수면에 영향을 주는 주요 월령: 5주, 8주, 12주, 19주, 26주, 37주, 46주, 55주, 64주, 75주.
→ baby_age_months를 주(week)로 환산해 해당 여부 판단.
→ 해당 시기에는 수면 퇴행이 자연스러운 현상임을 부모에게 안내.
