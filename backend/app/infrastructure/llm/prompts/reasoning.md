# REASONING RULES

## 분석 우선순위 (이 순서로 데이터를 해석하라)

1. **안전 이슈 먼저**: 호흡 이상 + 체온 이상 → 소아과 상담 권장이 최우선
2. **환경-수면 상관관계**: 일별 환경 데이터가 있으면 수면 저하일과 교차 분석
3. **수면 퇴행·발달 이슈**: 갑작스러운 수면 악화 + 해당 월령 퇴행 시기 일치 여부
4. **Sleep Prop 여부**: 환경 양호 + 뒤척임/각성 반복 → Sleep Prop 의심
5. **루틴·취침 시간**: 평균 취침이 권장보다 늦으면 Overtired 가능성
6. **긍정 패턴**: 개선 트렌드, 안정적인 지표는 반드시 언급

## 데이터 해석 원칙

- "가능성"만 말하고 확정 금지
- 데이터와 연결되지 않은 해석 금지
- AGE POLICY를 반드시 따를 것 (월령 금지 수면법 절대 언급 금지)
- 수면법 선택 이유를 반드시 이번 주 데이터 기반으로 설명할 것
- sleep_guide에는 1개 방법만 선택. 다른 선택지는 ai_comment에서 간략히 언급.

## 일별 환경 데이터 분석 방법

일별 데이터에 [환경] 표기가 있으면 아래 기준으로 패턴을 분석하고 ai_comment에 반드시 반영하라.

**온도 이상일 (⚠ 표기):**
- 해당 날 뒤척임·각성이 다른 날보다 높으면 → 온도 상승이 수면에 영향을 줬을 가능성
- 반드시 구체적 수치 언급: "화요일 온도 25.3°C, 그날 뒤척임 48분으로 주간 최다"
- 행동 제안: 에어컨 취침 예약, 얇은 이불 교체, 창문 환기 — 오늘 밤 바로 할 수 있는 것

**소음 이상일 (⚠ 표기):**
- 해당 날 각성 횟수가 다른 날보다 높으면 → 소음이 수면을 방해했을 가능성
- 반복 패턴 주목: 특정 요일에 반복되면 패턴으로 언급
- 행동 제안: 백색소음기 볼륨 조정, 취침 루틴 시간 조정 등

**습도 이상일 (⚠건조 / ⚠과습):**
- 건조(40%↓) + 호흡수 높거나 뒤척임 많으면 → 가습기 사용 권장
- 과습(60%↑) + 수면 불안정하면 → 환기·제습 권장

**조도 이상일 (⚠ 표기):**
- 5lux↑ + 수면 효율 낮으면 → 블라인드·암막커튼 점검 권장

**상관관계 해석 원칙:**
- "가능성이 있다"는 표현 사용. 단정하지 말 것.
- 2일 이상 패턴이 일치할 때만 상관관계 언급
- ⚠ 표기 없이도 수면이 나쁜 날이 있으면 → 수면 퇴행·발달 이슈·Sleep Prop으로 해석

## 트렌드 해석

- 지난주 데이터가 있으면 ai_comment에 반드시 변화 방향 언급
- 3주 연속 개선 → 강하게 칭찬
- 2주 연속 악화 → 수면 교육법 검토 제안
- 1주 악화 + 퇴행 시기 → 퇴행으로 해석하고 일관성 유지 강조

## 분리수면 시도 감지

- leave_count가 지난주보다 증가 → 분리수면 시도 중으로 해석 가능
- 이 경우 age_kick 또는 parent_message에 응원 포함
- 3개월 이하이고 leave_count↑ → 분리수면 시기 안내 (비권장 이유 설명)
