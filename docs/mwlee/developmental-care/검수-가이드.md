## 검수 항목별 체크포인트

### 1. dev_status (발달 상태)
- [ ] 해당 월령/주차의 실제 발달 마일스톤과 일치하는가
- [ ] 수면과 연관된 발달 내용이 포함되어 있는가
- [ ] 부모가 이해하기 쉬운 언어로 작성되었는가
- [ ] 의학적 진단 표현은 사용하지 않았는가

### 2. sleep_activities (추천 활동 3가지)
- [ ] 해당 월령에 실제로 가능한 활동인가
- [ ] 수면 개선에 직접적·간접적으로 도움이 되는가
- [ ] 구체적이고 실행 가능한 내용인가

### 3. vaccination (예방접종 안내)
- [ ] 질병관리청 최신 일정과 일치하는가 (research-reference.md 참조)
- [ ] 접종이 없는 달은 "이 달 정기 접종 없음"으로 올바르게 표기되었는가
- [ ] 주요 접종 월 (4, 6, 12, 15, 18개월)의 내용이 정확한가

### 4. separation_sleep_guide (분리수면 안내)
- [ ] 월령에 맞는 분리수면 권고 수준인가 (4개월 미만 = 비권장)
- [ ] 한국 부모의 불안·죄책감을 자극하지 않는가
- [ ] 수면 교육법 추천 시 월령 기준에 맞는가 (age_policy 참조)

### 5. 플래그 확인
- [ ] `wonder_weeks_leap`: 해당 원더윅스 번호가 올바른가
- [ ] `is_sleep_regression`: 수면 퇴행 시기가 올바르게 표시되었는가
  - 4개월 퇴행: 주 16~22
  - 8~10개월 퇴행: 주 33~44
  - 12개월 퇴행: 주 50~52
  - 18개월 퇴행: month 18
  - 24개월 퇴행: month 24

## DB 삽입 시 스키마 제안 (팀원 B 참고)

```sql
CREATE TABLE developmental_care (
    id              INT PRIMARY KEY,
    type            ENUM('weekly', 'monthly') NOT NULL,
    age_months      TINYINT UNSIGNED NOT NULL,
    age_weeks       TINYINT UNSIGNED,          -- weekly만 해당
    age_label       VARCHAR(50) NOT NULL,
    wonder_weeks_leap TINYINT UNSIGNED,        -- 1~10, NULL if none
    is_sleep_regression BOOLEAN DEFAULT FALSE,
    dev_status      TEXT NOT NULL,
    sleep_activity_1 VARCHAR(300) NOT NULL,
    sleep_activity_2 VARCHAR(300) NOT NULL,
    sleep_activity_3 VARCHAR(300) NOT NULL,
    vaccination     TEXT NOT NULL,
    separation_sleep_guide TEXT NOT NULL,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
