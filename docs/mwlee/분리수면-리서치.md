## 1. 분리수면 시작 적정 시기

### AAP (미국소아과학회) 2022년 업데이트 기준
- **생후 6개월까지**: 부모와 같은 방에서 재울 것 권고 (단, 침대는 분리)
- **이상적으로는 12개월까지** 동일 방 사용 권고 → SIDS 위험 최대 50% 감소
- **침대 공유(bed sharing)**: 어떤 상황에서도 비권장
- **수면 교육(독립 수면 훈련) 시작 적정 월령**: 생후 4~6개월 이후

### 월령별 준비도 요약

| 월령 | 상태 | 권고 |
|------|------|------|
| 0~3개월 | 생체 리듬 미발달, 야간 수유 필수 | 수면 교육 비권장 |
| 4~5개월 | 생체 리듬 발달 시작, 4개월 수면 퇴행 이후 | 준비 가능 시점 |
| 6개월+ | 야간 수유 없이 수면 가능 체중 도달 | 일반 권장 시점 |
| 9개월+ | 분리불안 심화 가능 | 시작이 늦을수록 난이도 상승 |

### 준비도 체크리스트 (프롬프트 반영)
- 수유 없이 2~3시간 이상 수면 가능한가
- 4개월 수면 퇴행 이후인가 (수면 구조 성인형 전환 완료 여부)
- Sleep Prop 의존이 있는가 (있으면 먼저 개선 후 시도)

## 2. 주요 수면 교육법 비교

| 방법 | 권장 월령 | 효과 속도 | 부모 부담 | 핵심 원리 |
|------|---------|---------|---------|---------|
| 쉬닥법 | 0~4개월 | 중간 | 낮음 | 등 토닥 + "쉬-" 소리, 안아 올리지 않음 |
| 픽업앤다운(PUPD) | 3~6개월 | 느림 | 매우 높음 | 울면 안아 진정 후 눕히기 반복 |
| 퍼버법 | 6개월+ | 빠름 (3~7일) | 높음 | 점진적 체크인 간격 늘리기 |
| 의자법 | 6개월+ | 중간 (2~3주) | 중간 | 의자를 매 2~3일마다 멀리 이동 |
| 완전 소거(CIO) | 6개월+ | 매우 빠름 (3~5일) | 매우 높음 | 체크인 없이 자체 진정 유도 |

### 퍼버법 연구 근거
- **Gradisar et al. (2016, Pediatrics)**: 퍼버법 시행 후 5년 추적
  - 아동 정서·행동·부모-자녀 애착에 **부정적 영향 없음**
  - 코르티솔(스트레스 호르몬) 장기 수치 차이 없음
  - 수면 개선 효과: **2~7일 내** 나타남

## 3. 분리수면과 애착의 관계

### 핵심 결론
- 행동적 수면 교육은 수면을 개선하면서도 **애착을 해치지 않음** (52개 연구 메타분석)
- 오히려 수면 교육 후 **영아의 애착 안정성이 증가**하는 경향 관찰
- 영국 켄트대 연구 (178쌍 추적): 수면 형태와 애착 간 유의미한 상관관계 없음

### 왜 수면 교육이 애착에 도움이 되는가
1. 부모 수면 개선 → 낮 동안 아이 신호에 더 민감하게 반응
2. 모 우울증 감소 → 반응성 향상 → 애착 안정화
3. 수면 교육 그룹에서 모 우울 척도 통계적으로 유의미하게 개선

### 프롬프트에 반영된 방향
- 한국 부모의 "분리수면 = 냉정한 부모" 인식에 공감 + 과학적 근거로 안심
- "아이의 수면 독립을 돕는 과정"으로 프레이밍

## 4. 수면 퇴행 — 시기별 원인

| 시기 | 원인 | 특징 | 지속 기간 |
|------|------|------|---------|
| **4개월** | 수면 구조 신생아형→성인형 영구 전환 | 가장 중요. 되돌릴 수 없음. | 2~6주 |
| **8~10개월** | 기기·서기 발달 + 분리불안 폭발 | 분리수면 첫 시도 가장 어려운 시기 | 2~4주 |
| **12개월** | 걷기 시작, 낮잠 2→1회 전환 | 낮잠 거부, 밤잠 분절 | 2~4주 |
| **18개월** | 언어 폭발, 독립심↑ vs 의존↑ 충돌 | 취침 거부, 조기 기상 | 2~6주 |
| **24개월** | 상상력 발달, 악몽 가능 | 취침 거부, 형제 출생 등 환경 변화 | 2~4주 |

### 4개월 퇴행이 핵심인 이유
- 수면 구조가 영구적으로 바뀜 → 자기진정 능력이 없으면 이후 모든 수면 사이클마다 깨서 도움 요청
- 이 시기 이후 Drowsy But Awake 연습을 시작하는 것이 장기 수면 독립의 핵심

## 5. 각성 창 (Wake Window)

아기가 깨어 있을 수 있는 최대 시간. 초과 시 Overtired → 코르티솔 분비 → 오히려 재우기 더 어려워짐.

| 월령 | 각성 창 |
|------|--------|
| 0~1개월 | 45~60분 |
| 2~3개월 | 60~90분 |
| 4~5개월 | 90~120분 |
| 6~8개월 | 2~3시간 |
| 9~12개월 | 3~4시간 |
| 12~18개월 | 4~6시간 |

**흔한 실수**: "더 피곤하면 더 잘 잔다" → 실제로는 각성 창 초과 시 코르티솔로 더 안 잠.

---

## 6. Sleep Prop (수면 보조 도구)

아기가 잠들기 위해 반드시 필요로 하는 외부 조건. 수면 사이클 전환 시마다 같은 조건 요구 → 잦은 야간 각성 주원인.

**문제 Props**: 젖/우유 빨며 잠들기, 안겨서 완전히 잠든 뒤 눕히기, 취침 시마다 쪽쪽이 삽입, 흔들거나 토닥여야 잠드는 경우

**괜찮은 Props**: 백색소음, 어두운 환경, 수면 인형(6개월+), 일관된 취침 루틴

**해결 원칙 — Drowsy But Awake**:
- 졸리지만 아직 눈 뜬 상태로 눕히기
- 수면 사이클 전환 시 스스로 재잠드는 능력 발달
- 적용 가능 시기: 생후 4개월 이후

## 7. 분리불안 대처

**발생 시기**: 8~9개월 (영속성 개념 발달), 18개월 (언어·인지 격차)

**대처 루틴**:
1. **굿나잇 루틴 일관화**: 매일 같은 순서 (목욕→수유→자장가→굿나잇 인사→소등)
2. **예고 후 자리 비움**: "잠깐 다녀올게" — 몰래 나가지 않기
3. **피크어부 놀이**: 낮 동안 반복 → "엄마는 사라져도 돌아온다" 영속성 강화
4. **낮 접촉 충분히**: 낮 동안 애착 욕구 충족 → 취침 시 분리 저항 감소

## 8. 한국 문화 특수성

- 동아시아 문화권: 전통적으로 부모-자녀 동침이 일반적
- 국내 일부 전문가: "격리 수면은 한국 정서에 맞지 않다"는 견해 존재
- 한국 부모 주요 걱정: 애착 손상, 트라우마, "냉정한 부모"라는 사회적 시선, 조부모 반대

**프롬프트 처리 방향**:
- 부모의 불안에 공감하되, 과학적 근거로 방향 제시
- "냉정한 육아" ❌ → "수면 독립을 돕는 과정" ✅
- 강요하지 않고 "시도해볼 수 있어요" 수준으로 제안

## 9. 분리수면 시 흔한 실수

| 실수 | 해결책 |
|------|--------|
| 불일관성 (방법을 3~4일만 시도) | 최소 1~2주 일관 유지. 두 부모가 방법 통일 |
| Sleep Prop 의존 형성 | Drowsy But Awake 원칙. 수유는 취침 20~30분 전 완료 |
| 각성 창 초과 (Overtired) | 월령별 각성 창 엄수. 졸음 신호 즉시 반응 |
| 취침 시간이 너무 늦음 | 6~12개월: 오후 6:30~7:30 취침 최적 |
| 퇴행 중 기존 루틴 포기 | 퇴행 중 새 교육 시작 자제. 기존 루틴 유지 |
| 한 명이 몰아서 담당 | 두 부모 역할 분담 → 번아웃 방지 |
