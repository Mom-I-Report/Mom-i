# 데이터 스키마 변경 사항

> 작성일: 2026-05-28  
> 변경 파일: `backend/app/domain/report/schemas.py`, `report_service.py`, `gemini_client.py`

---

## 변경 배경

기존 구조의 한계:
- **수면 데이터**: 일별 7개 (`SleepDay` per day) ✅
- **환경 데이터**: 주간 집계 1개 (`EnvironmentData` — weekly avg/max/min만) ⚠️

→ "화요일에 온도가 높았고 그날 잠을 못 잤다" 수준의 분석 **불가능**  
→ 일별 환경 데이터를 mom-i 서버에서 제공 가능하다는 확인 후 추가 결정

---

## 변경 내용: SleepDay 확장

### 추가된 필드

```python
class SleepDay(BaseModel):
    # ... 기존 필드 유지 ...

    # 일별 환경 데이터 (mom-i 서버 제공 시 포함)
    env_temp_max: Optional[float] = None      # 당일 최고 실내 온도 (°C)
    env_db_max: Optional[int] = None          # 당일 최고 소음 (dB)
    env_humidity_avg: Optional[float] = None  # 당일 평균 습도 (%)
    env_bright_avg: Optional[float] = None    # 당일 평균 조도 (lux)
```

### 설계 결정

| 결정 | 이유 |
|------|------|
| Optional 처리 | 기존 API 하위 호환 유지. mom-i 서버 미제공 시에도 동작 |
| SleepDay에 포함 | 날짜별로 수면↔환경을 한 묶음으로 처리하는 것이 분석에 자연스러움 |
| EnvironmentData 유지 | 주간 집계도 여전히 필요 (weekly avg는 호흡·체온 판단에 사용) |

```json
"sleep": [
  { "date": "2026-05-26", "sleep_min": 540, "restless_min": 48 }
]
```

### 요청 형태 (변경 후)

```json
"sleep": [
  {
    "date": "2026-05-26",
    "sleep_min": 540,
    "restless_min": 48,
```

## Gemini 프롬프트 반영 방식

`gemini_client.py`의 `_build_prompt()`에서 일별 라인 생성 시 환경 이상치 자동 표기:

```
월: 수면 9.5h / 뒤척임 22분 / 각성 2회  [환경: 온도최고 20.1°C / 소음최고 44dB]
화: 수면 8.2h / 뒤척임 48분 / 각성 7회  [환경: 온도최고 25.3°C ⚠ / 소음최고 63dB ⚠]
수: 수면 9.8h / 뒤척임 17분 / 각성 1회  [환경: 온도최고 20.4°C / 소음최고 41dB]
```

⚠ 표기 기준:
- `env_temp_max` > 22.0°C (신생아는 동일 기준 적용, 월령 3개월 이하도 22°C)
- `env_db_max` > 50dB
- `env_humidity_avg` < 40% 또는 > 60%
- `env_bright_avg` > 5lux

AI는 ⚠ 표기된 날과 수면 지표(뒤척임·각성)를 자동 교차 분석.

## 기대 효과

### 이전 출력 (주간 집계만 있을 때)
> "이번 주 실내 온도 평균 22.1°C로 권장 범위 내였습니다."

### 이후 출력 (일별 환경 데이터 적용 시)
> "화요일 실내 온도가 25.3°C로 올라갔고, 그날 뒤척임이 48분으로 주간 최다였습니다.  
> 에어컨 취침 예약(20°C)을 설정해두시면 이런 날 수면 안정에 도움이 될 수 있어요.  
> 온도가 안정적이었던 수요일(20.4°C)에는 뒤척임이 17분으로 뚝 떨어졌다는 점도 참고해 보세요."

## 팀원 전달 사항

**mom-i 서버 담당 팀원에게:**
- `POST /reports/generate` 요청 시 `sleep` 배열 각 항목에 4개 환경 필드 추가 요청
- 필드명: `env_temp_max`, `env_db_max`, `env_humidity_avg`, `env_bright_avg`
- 타입: float/int, 모두 Optional (없으면 null 또는 필드 생략 가능)
- EMTAKE 릴레이에서 일별 집계 후 넘겨주면 됨
