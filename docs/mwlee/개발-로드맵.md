## 발달 케어 콘텐츠 작업 계획 (mwlee 담당)

### 범위
- 대상 월령: 생후 **4개월 ~ 36개월**
- 총 데이터 수: **약 200개**
- 구성: 주차별 (4~12개월 구간) + 월령별 (12~36개월 구간)

### 각 항목 포함 내용
```
월령/주차:       "생후 16주 (4개월)"
발달 상태:       "이 시기 아기는 ..."
추천 활동:       "수면에 도움되는 놀이 3가지"
예방접종 안내:   "이 시기 맞아야 할 예방접종 (국가필수예방접종 기준)"
분리수면 안내:   "4개월 미만 → 비권장 안내 / 4개월+ → 시작 권장"
```

### 작업 방식
1. Claude가 월령별 초안 생성 (발달 마일스톤 + 예방접종 일정)
2. mwlee가 도메인 지식으로 검수·수정
3. 검수 완료 데이터 → 팀원 B가 DB에 삽입
