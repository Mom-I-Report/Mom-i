## 1. 작업 배경

맘아이(M-Take) 리포트 서버에서 EMTAKE 프로토콜 상에 명시된 **호흡수(Breath)**,
**체온상승(Temp)**, **월간 집계(monthly)** 데이터가 코드에 전혀 반영되지 않은 상태였다.
또한 Gemini 클라이언트에 재시도, 섹션 검증, 비동기 처리 등 운영 수준의 신뢰성
장치가 없었다.

AI 리포트 담당(D 역할)으로서 아래 두 축을 중심으로 작업을 수행했다.

1. **EMTAKE 프로토콜 완전 반영** — 누락 데이터 3종 전 레이어 통합
2. **Gemini 클라이언트 운영 수준 고도화** — 비동기·재시도·검증·캐시·토큰 로깅·Thinking Budget

## 3. 세부 작업 내역

### 3-1. EMTAKE 프로토콜 누락 데이터 3종 통합

EMTAKE 프로토콜 PDF(`Mom-i Relay Server data set & protocol (예).pdf`) 분석 결과,
아래 3가지 CMD 데이터가 프로토콜에는 존재하나 코드에 없었음을 확인.

| CMD | 데이터 | 필드 |
|-----|--------|------|
| `CMD: Breath` | 수면 중 호흡수 | `breath_min`, `breath_max`, `breath_avg` (회/분) |
| `CMD: Temp` | 수면 중 체온상승 | `body_temp_min`, `body_temp_max`, `body_temp_avg` (°C) |
| `CMD: SleepData` | 월간 평균 | `month_gs` (월간수면h), `month_pr` (월간뒤척임h) |

**domain/report/entity.py — WeeklyData 컬럼 추가**

```python
class WeeklyData(Base):
    __tablename__ = "Weekly_Data"
    # 기존 컬럼들 ...
    breath_json    = Column(JSON, nullable=False)   # 수면 중 호흡수 (회/분)
    body_temp_json = Column(JSON, nullable=False)   # 수면 중 체온 상승 (°C)
    monthly_json   = Column(JSON, nullable=False)   # 월간 평균 집계
```

> ⚠ SQLite는 ALTER TABLE JSON 컬럼 추가 미지원. 기존 `m_take.db` 삭제 후 재시작 필요.

**domain/report/schemas.py — 신규 Pydantic 모델 5개**

```python
class BreathData(BaseModel):      # 요청 입력용
    breath_min: int
    breath_max: int
    breath_avg: int

class BodyTempData(BaseModel):    # 요청 입력용
    body_temp_min: float
    body_temp_max: float
    body_temp_avg: float

class MonthlySummary(BaseModel):  # 요청 입력용
    month_sleep_h: float

    breath_min: int
    breath_max: int
    breath_avg: int
    is_normal: bool
    normal_range: str   # "20~40회/분 (생후 6~12개월 기준)"

class BodyTempSummary(BaseModel): # 응답 출력용 (상태 판정 포함)
    body_temp_min: float
    body_temp_max: float
    body_temp_avg: float
    status: str         # "정상" | "미열 주의" | "발열 의심"
```

### 3-2. 리포트 서비스 6단계 파이프라인 구축

**application/report/report_service.py**

```
Step 1  원본 저장      Weekly_Data upsert (breath·body_temp·monthly 포함)
Step 2  캐시 확인      기존 리포트 있으면 Gemini 재호출 없이 즉시 반환
Step 3  이전 조회      get_recent_weekly_data(weeks=2) — DB 쿼리 1회
Step 4  집계           summary / daily / breath_summary / body_temp_summary / trend
Step 5  AI 생성        await generate_insight() — 재시도·검증·로깅 포함
Step 6  저장·반환      Generated_Reports upsert → GenerateReportResponse
```

**주요 개선 포인트:**

- **async 전환**: `generate_report()`, `get_report_history()` 모두 `async def`
- **DB 쿼리 1회**: `prev_data = get_recent_weekly_data(weeks=2)` 한 번 조회 후
  `_build_trend()`와 `_build_ai_context()` 모두 재사용 (중복 쿼리 제거)
- **캐시**: 동일 `(ser_no, week_start)` 리포트 존재 시 Gemini 미호출
- **호흡수 정상 판정**: AAP 기준 월령별 정상 범위 적용

```python
# AAP 기준 월령별 정상 호흡수 (회/분)
_BREATH_RANGES = [
    (3,  30, 55),   # 0~3개월
    (6,  25, 50),   # 3~6개월
    (12, 20, 40),   # 6~12개월
    (24, 20, 35),   # 12~24개월
    (999,20, 30),   # 24개월 이상
]

def _get_breath_normal_range(baby_age_months: int) -> tuple[int, int, str]:
    for max_age, low, high in _BREATH_RANGES:
        if baby_age_months < max_age:
            return low, high, f"{low}~{high}회/분 ..."
```

- **체온 판정 기준**:
  - `≤ 37.4°C` → 정상
  - `37.5 ~ 37.9°C` → 미열 주의
  - `≥ 38.0°C` → 발열 의심

### 3-3. Gemini 클라이언트 운영 수준 고도화

**infrastructure/llm/gemini_client.py — 전면 재작성**

#### (1) 모델 교체: 1.5-flash → 2.5-flash

```python
_model = genai.GenerativeModel(
    model_name="gemini-2.5-flash",
    system_instruction=_SYSTEM_PROMPT,
)
```

#### (2) 비동기 전환

```python
async def generate_insight(ctx: dict) -> str:
    ...
    result = await _call_gemini(prompt)

async def _call_gemini(prompt: str) -> str:
    response = await _model.generate_content_async(prompt, generation_config=...)
```

#### (3) 재시도 — 지수 백오프 (1s → 2s → 4s)

```python
_MAX_ATTEMPTS = 3
_BACKOFF_BASE = 1.0
_RETRYABLE_KEYWORDS = ("429", "quota", "rate", "503", "unavailable")

for attempt in range(1, _MAX_ATTEMPTS + 1):
    try:
        response = await _model.generate_content_async(...)
        return response.text.strip()
    except Exception as exc:
        if not _is_retryable(exc) or attempt == _MAX_ATTEMPTS:
            raise
        wait = _BACKOFF_BASE * (2 ** (attempt - 1))
        await asyncio.sleep(wait)
```

#### (4) 5섹션 출력 검증

```python
_REQUIRED_SECTIONS = [
    "### 이번 주 총평",
    "### 수면 패턴 분석",
    "### 호흡 및 체온 분석",
    "### 환경 영향 분석",
    "### 부모 조언",
]

missing = _validate_sections(result)
if missing:
    # 누락 섹션 명시해 보정 재호출
    fix_prompt = prompt + f"\n\n[주의] 아래 섹션이 누락되었습니다...\n" + "\n".join(missing)
    result = await _call_gemini(fix_prompt)
```

#### (5) 토큰 사용량 로깅

```python
def _log_token_usage(response) -> None:
    meta = response.usage_metadata
    logger.info(
        "[Gemini 토큰] 입력: %d / 출력: %d / 합계: %d",
        meta.prompt_token_count,
        meta.candidates_token_count,
        meta.total_token_count,
    )
```

#### (6) Thinking Budget — 1024 토큰

```python
generation_config = {
    "thinking_config": {"thinking_budget": 1024},
}
```

### 3-4. 시스템 프롬프트 완성

**infrastructure/llm/prompts/system_prompt.md**

이전에 `(도메인 전문가 작성 예정)` 플레이스홀더로 비어 있던 부분을 채웠다.

- **월령별 권장 수면 시간**: AAP 기준 (0~3개월 14~17h, 3~6개월 12~15h 등)
- **월령별 호흡수 정상 범위**: AAP 기준표
- **체온 판정 기준**: 정상/미열 주의/발열 의심
- **뒤척임 해석 기준**: 30분 미만 정상, 30~60분 주의, 60분 이상 개선 필요
- **실내 환경 기준**: 권장 온도 18~22°C, 권장 소음 50dB 이하
- **5섹션 출력 형식**: 섹션별 구체적 작성 기준 명시
