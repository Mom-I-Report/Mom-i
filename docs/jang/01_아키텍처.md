## 인프라 구성 상세

### AWS 서비스 선택

| 서비스 | 용도 | 스펙(초기) | 월 비용 |
|--------|------|-----------|--------|
| **EC2** | API 서버, 분석 엔진 | t4g.small | ~1.5만 원 |
| **RDS** | 사용자 · 수면 데이터 | db.t4g.micro (PostgreSQL) | ~2만 원 |
| **DynamoDB** | 리포트 캐시 · 메타 | On-demand | ~5천 원 |
| **S3** | 리포트 파일 저장 | Standard | ~3천 원 |
| **CloudFront** | 리포트 파일 CDN | - | ~2천 원 |
| **Lambda** | 주간 리포트 생성 스케줄러 | - | 거의 무료 |
| **SNS** | 푸시 알림 | - | ~1천 원 |
| **CloudWatch** | 로그 · 모니터링 | - | ~2천 원 |
| **합계** | | | **약 4~6만 원/월** |

## 데이터 흐름 (Data Flow)

### 1. 카메라 → 서버 (실시간 수집)
```
Mom-i 카메라
  → POST /api/v1/sleep-data
  → 데이터 검증 (필드 누락 체크)
  → RDS sleep_sessions 테이블 저장
```

### 2. 주간 리포트 생성 (매주 월요일 자동)
```
AWS Lambda (Cron: 매주 월요일 오전 7시)
  → 7일치 수면 데이터 취합 (RDS 쿼리)
  → 수면 분석 엔진 실행 (평균, 추이, 이상 탐지)
  → Gemini API 호출 (분석 결과 + 개월수 프롬프트)
  → 리포트 데이터 조합
  → DynamoDB에 리포트 메타 저장
  → S3에 리포트 이미지/JSON 저장
  → SNS → 푸시 알림 발송
```

### 3. 앱 리포트 조회
```
앱 GET /api/v1/reports?cameraId=xxx
  → DynamoDB 캐시 조회
  → 리포트 목록 + S3 URL 반환
  → 앱에서 화면 렌더링
```

## 보안 설계

| 항목 | 방법 |
|------|------|
| API 인증 | JWT 토큰 (카메라 + 앱 모두) |
| HTTPS | ACM + CloudFront (무료 SSL) |
| DB 접근 | VPC 내부 통신만 허용 |
| LLM API Key | AWS Secrets Manager 관리 |
| 데이터 암호화 | S3 SSE + RDS 암호화 |

## LLM 선택 비교

| 모델 | 비용/건 | 속도 | 정확도 | 선택 |
|------|--------|------|--------|------|
| **Gemini 1.5 Flash** | **0.5~1원** | ⚡ 빠름 | ✅ 충분 | ✅ **1순위** |
| GPT-4o Mini | 2~4원 | 보통 | ✅ 좋음 | 🔄 비교 |
| GPT-4o | 30~50원 | 보통 | ⭐ 최고 | ❌ 비용 초과 |

**결론:** Gemini 1.5 Flash를 기본 모델로, 품질 미달 시 GPT-4o Mini로 fallback
