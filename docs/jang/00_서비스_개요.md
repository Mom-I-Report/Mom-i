## 핵심 목표 (QCD)

### Q — Quality (품질)
- 부모가 공감하고 안심할 수 있는 **톤앤매너** 유지
- LLM 기반 **전문 수면 가이드라인** 제공 (개월수 맞춤)
- **주간 리포트 조회율 75%** 이상

### C — Cost (비용)
- 리포트 1건당 LLM 비용 **1원 미만** (Gemini Flash 기준)
- AWS 운영비 월 **4~6만 원** 수준 유지
- 비용 최적화 전략: 캐싱 + 배치 처리 + LLM 호출 최소화

### D — Delivery (납기)
- 계약일로부터 **12주 내 완료**
- 중간 산출물(시뮬레이터, 리포트 샘플) 일정 내 제출
- 엠테이크 측 최종 검수 및 승인 후 인도

## 서비스 흐름 (Overview)

```
[Mom-i 카메라]
    │  수면 데이터 전송 (JSON / 주기적)
    ▼
[백엔드 서버 — AWS EC2]
    │  수면 데이터 저장
    ▼
[RDS PostgreSQL / DynamoDB]
    │  7일치 데이터 취합
    ▼
[분석 엔진 — Python/Node]
    │  수면 지표 계산 (평균, 뒤척임, 추이)
    ▼
[LLM API — Gemini 1.5 Flash]
    │  전문 프롬프트 → 가이드라인 텍스트 생성
    ▼
[리포트 생성 모듈]
    │  데이터 + AI 텍스트 합성 → 리포트 저장 (S3)
    ▼
[앱 API — REST]
    │  리포트 조회 API 응답
    ▼
[부모 앱 — 리포트 탭]
    📱 주간 리포트 열람 + 히스토리 조회
```
