# 백엔드 분업 (5인)

> 기간: 3일 | 스택: Node.js + TypeScript + Express + Prisma + PostgreSQL

---

## A — 인증 & 사용자/카메라 관리

- 회원가입 / 로그인 (JWT 발급)
- JWT 인증 미들웨어
- 내 정보 조회 (`GET /users/me`)
- 카메라 등록 및 조회 (`GET/POST /cameras`)
- 아이 프로필 관리 (`baby_profiles`)

---

## B — 수면 데이터 수신 & 분석 엔진

- 카메라 → 서버 수면 데이터 수신 (`POST /sleep-data`)
- 수면 데이터 DB 저장 (`sleep_sessions`)
- 수면 점수 계산 알고리즘 (실수면/온도/소음 기반)
- 개발용 더미 데이터 시뮬레이터 (`scripts/simulator.ts`)

---

## C — 리포트 조회 API

- 주간 리포트 목록 조회 (`GET /reports`)
- 리포트 상세 조회 (`GET /reports/:reportId`)
- 히스토리 점수 추이 계산 (전주 대비 up/down/same)
- 수동 리포트 생성 트리거 (`POST /reports/generate`)

---

## D — AI 리포트 생성 파이프라인

- Gemini API 연동 (`llmService.ts`)
- 개월수별 프롬프트 작성 (0~3개월 / 4~6개월 / 7~9개월 / 10~12개월)
- 수면 데이터 → AI 분석 → 리포트 저장 오케스트레이터
- LLM 실패 시 템플릿 기반 Fallback 처리

---

## E — 인프라 & 알림

- Docker + PostgreSQL 로컬 환경 셋업 (`docker-compose.yml`)
- Prisma 스키마 마이그레이션 실행
- 공통 에러 핸들러 미들웨어
- 푸시 알림 발송 서비스 (`notificationService.ts`)
- 알림 이력 조회 / 읽음 처리 API

---
