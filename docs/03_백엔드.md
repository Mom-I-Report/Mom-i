## 핵심 서비스 로직

### 1. 수면 분석 엔진 (`sleepAnalysisService`)

```typescript
interface SleepAnalysisResult {
  avgTotalSleep: number;
  avgActualSleep: number;
  avgTossing: number;
  avgTemperature: number;
  avgNoiseDb: number;
  sleepScore: number;           // 0~100 종합 점수
  scoreTrend: 'up' | 'down' | 'same';
  bestDay: DailySleep;
  worstDay: DailySleep;
  anomalies: string[];          // 이상 감지 항목
}

// 수면 점수 계산 알고리즘
function calculateSleepScore(data: DailySleep): number {
  // 실수면 비율 (40점)
  const sleepRatio = data.actualSleepMinutes / data.totalMinutes;
  const sleepScore = Math.min(sleepRatio * 40, 40);

  // 총 수면 시간 (30점) — 7개월 아이 권장 14~16시간
  const idealMinutes = 840; // 14시간
  const timeDiff = Math.abs(data.totalMinutes - idealMinutes);
  const timeScore = Math.max(0, 30 - (timeDiff / 30));

  // 환경 온도 (20점) — 권장 20~22°C
  const tempDiff = Math.abs(data.avgTemperature - 21);
  const tempScore = Math.max(0, 20 - (tempDiff * 5));

  // 소음 (10점) — 30dB 이하 양호
  const noiseScore = data.avgNoiseDb <= 30 ? 10 : Math.max(0, 10 - (data.avgNoiseDb - 30) * 0.5);

  return Math.round(sleepScore + timeScore + tempScore + noiseScore);
}
```

### 2. LLM 서비스 (`llmService`)

```typescript
// Gemini 1.5 Flash 기반 리포트 텍스트 생성
async function generateReportText(
  analysis: SleepAnalysisResult,
  babyAgeMonth: number,
  historyData?: SleepAnalysisResult[]  // 과거 1~2달 데이터
): Promise<AIAnalysis> {

  const prompt = buildPrompt(analysis, babyAgeMonth, historyData);

  const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });
  const result = await model.generateContent(prompt);

  return parseAIResponse(result.response.text());
}

// 개월수 기반 프롬프트 생성
function buildPrompt(analysis, ageMonth, history) {
  const ageGuidelines = AGE_GUIDELINES[Math.floor(ageMonth / 3)]; // 0~3, 4~6, 7~9...

  return `
    당신은 영유아 수면 전문가입니다. 다음 데이터를 분석하고 따뜻하고 전문적인 수면 리포트를 작성해주세요.

    [아이 정보]
    - 개월 수: ${ageMonth}개월
    - 이 시기 권장 수면: ${ageGuidelines.recommendedSleep}
    - 발달 특성: ${ageGuidelines.characteristics}

    [이번 주 수면 데이터]
    - 평균 총 수면: ${Math.round(analysis.avgTotalSleep / 60)}시간 ${analysis.avgTotalSleep % 60}분
    - 평균 실제 수면: ${analysis.avgActualSleep}분
    - 평균 뒤척임: ${analysis.avgTossing}분
    - 평균 온도: ${analysis.avgTemperature}°C
    - 수면 점수: ${analysis.sleepScore}점
    - 이상 항목: ${analysis.anomalies.join(', ') || '없음'}

    [과거 데이터 비교]
    ${history ? `지난 달 평균 점수: ${history.map(h => h.sleepScore).join(', ')}` : '첫 주 데이터'}

    다음 JSON 형식으로 응답해주세요:
    {
      "overallComment": "전체 코멘트 (2~3문장, 따뜻한 톤)",
      "tips": [
        {
          "icon": "이모지",
          "title": "팁 제목",
          "content": "상세 내용 (1~2문장)",
          "tag": "좋음|주의|양호",
          "tagColor": "good|caution"
        }
      ],
      "ageGuidance": {
        "title": "${ageMonth}개월 수면 발달 가이드",
        "content": "이 개월 수 특성과 권장 케어"
      }
    }
  `;
}
```

## 비용 최적화 전략

### LLM 호출 최소화
```
1. 캐싱: 동일 주간 데이터로 재생성 요청 시 캐시 반환
2. 배치 처리: 매주 월요일 오전 7시 일괄 생성 (즉시 생성 X)
3. 사전 분석: 수면 점수, 추이 등은 LLM 없이 직접 계산
4. 토큰 제한: 응답 max_tokens 500으로 제한
```

### 비용 모니터링
```typescript
// 리포트 생성 시 토큰 사용량 로깅
```

## 에러 처리 및 Fallback

| 상황 | 대응 |
|------|------|
| LLM 응답 오류 | 템플릿 기반 기본 리포트 생성 (fallback) |
| 카메라 데이터 누락 | 누락일은 전주 평균값으로 대체 후 알림 |
| DB 연결 실패 | DynamoDB 캐시 우선 조회, 복구 후 동기화 |
| API 비용 초과 | 일일 호출 한도 설정, 초과 시 큐 처리 |
