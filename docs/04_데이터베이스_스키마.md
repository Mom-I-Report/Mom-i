# 🗄️ Mom-i 데이터베이스 스키마
> 최종 수정: 2026.04.16 | PostgreSQL (RDS) + DynamoDB

---

## 데이터베이스 구성

| DB | 용도 | 이유 |
|----|------|------|
| **PostgreSQL (RDS)** | 사용자, 카메라, 수면 세션 | 관계형 데이터, 복잡한 집계 쿼리 |
| **DynamoDB** | 리포트 캐시, 메타데이터 | 빠른 조회, 유연한 스키마 |

## PostgreSQL 스키마

### ERD 관계도

```
users ──────────< cameras >─────────< sleep_sessions
  1                  1~N                   1~N
  │                  │
  │              baby_profiles
  │                  │
  └──────────────────┘

reports ──────── report_ai_contents
   1                   1
```

### 테이블: `users` (사용자)

```sql
CREATE TABLE users (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email         VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  name          VARCHAR(100) NOT NULL,          -- 부모 이름
  phone         VARCHAR(20),
  created_at    TIMESTAMPTZ DEFAULT NOW(),
  updated_at    TIMESTAMPTZ DEFAULT NOW(),
  deleted_at    TIMESTAMPTZ                     -- 소프트 삭제
);

CREATE INDEX idx_users_email ON users(email);
```

---

### 테이블: `cameras` (Mom-i 카메라 기기)

```sql
CREATE TABLE cameras (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  camera_id   VARCHAR(50) UNIQUE NOT NULL,      -- 기기 고유 ID (e.g., CAM-A1B2C3)
  name        VARCHAR(100),                     -- 별명 (e.g., "민준이 방")
  is_active   BOOLEAN DEFAULT true,
  registered_at TIMESTAMPTZ DEFAULT NOW(),
  last_seen_at  TIMESTAMPTZ,                    -- 마지막 데이터 수신 시각
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_cameras_user_id ON cameras(user_id);
CREATE INDEX idx_cameras_camera_id ON cameras(camera_id);
```

---

### 테이블: `baby_profiles` (아이 정보)

```sql
CREATE TABLE baby_profiles (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  camera_id     UUID NOT NULL REFERENCES cameras(id) ON DELETE CASCADE,
  name          VARCHAR(50) NOT NULL,           -- 아이 이름
  birth_date    DATE NOT NULL,                  -- 생년월일
  gender        VARCHAR(10),                    -- 'male' | 'female' | 'unknown'
  avatar_emoji  VARCHAR(10) DEFAULT '🍼',
  created_at    TIMESTAMPTZ DEFAULT NOW(),
  updated_at    TIMESTAMPTZ DEFAULT NOW()
);

-- 카메라당 1명의 아이 (1:1)
CREATE UNIQUE INDEX idx_baby_camera_id ON baby_profiles(camera_id);
```

### 테이블: `sleep_sessions` (일별 수면 세션)

```sql
CREATE TABLE sleep_sessions (
  id                   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  camera_id            UUID NOT NULL REFERENCES cameras(id) ON DELETE CASCADE,
  session_date         DATE NOT NULL,            -- 수면 날짜 (기상 기준)

  -- 시간 정보
  bedtime              TIMESTAMPTZ,              -- 취침 시각
  wake_time            TIMESTAMPTZ,              -- 기상 시각
  total_minutes        SMALLINT NOT NULL,        -- 총 수면 시간(분)
  actual_sleep_minutes SMALLINT NOT NULL,        -- 실제 수면 시간(분)
  tossing_minutes      SMALLINT NOT NULL,        -- 뒤척임 시간(분)

  -- 환경 데이터
  avg_temperature      DECIMAL(4,1),             -- 평균 온도 (°C)
  max_temperature      DECIMAL(4,1),             -- 최고 온도
  min_temperature      DECIMAL(4,1),             -- 최저 온도
  avg_noise_db         SMALLINT,                 -- 평균 소음 (dB)

  -- 분석 결과
  sleep_score          SMALLINT,                 -- 수면 점수 (0~100)

  -- 원본 데이터
  raw_data_path        VARCHAR(500),             -- S3 경로 (원천 데이터)

  -- 메타
  created_at           TIMESTAMPTZ DEFAULT NOW(),

  -- 제약
  CONSTRAINT check_valid_score CHECK (sleep_score BETWEEN 0 AND 100),
  CONSTRAINT check_total_minutes CHECK (total_minutes > 0),
  CONSTRAINT unique_session UNIQUE (camera_id, session_date)
);

CREATE INDEX idx_sessions_camera_date ON sleep_sessions(camera_id, session_date DESC);
CREATE INDEX idx_sessions_date ON sleep_sessions(session_date DESC);
```

### 테이블: `reports` (주간 리포트)

```sql
CREATE TABLE reports (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  camera_id       UUID NOT NULL REFERENCES cameras(id) ON DELETE CASCADE,

  -- 기간
  week_start      DATE NOT NULL,                 -- 주 시작일 (월요일)
  week_end        DATE NOT NULL,                 -- 주 종료일 (일요일)
  week_number     SMALLINT,                      -- 해당 월의 주차

  -- 주간 통계 (집계값)
  avg_total_sleep      SMALLINT,                 -- 평균 총 수면(분)
  avg_actual_sleep     SMALLINT,                 -- 평균 실수면(분)
  avg_tossing          SMALLINT,                 -- 평균 뒤척임(분)
  avg_temperature      DECIMAL(4,1),             -- 평균 온도
  avg_noise_db         SMALLINT,                 -- 평균 소음

  -- 점수
  sleep_score          SMALLINT,                 -- 주간 수면 점수
  score_trend          VARCHAR(10),              -- 'up' | 'down' | 'same'
  prev_week_score      SMALLINT,                 -- 전주 점수 (비교용)

  -- 특별 날
  best_day             DATE,
  worst_day            DATE,
  best_day_score       SMALLINT,
  worst_day_score      SMALLINT,

  -- 상태
  status          VARCHAR(20) DEFAULT 'PENDING', -- PENDING | GENERATING | COMPLETED | FAILED
  generated_at    TIMESTAMPTZ,                   -- 생성 완료 시각

  -- 비용 추적
  llm_input_tokens    INTEGER,                   -- LLM 입력 토큰 수
  llm_output_tokens   INTEGER,                   -- LLM 출력 토큰 수
  llm_cost_krw        DECIMAL(6,1),              -- LLM 비용 (원)

  -- 메타
  created_at      TIMESTAMPTZ DEFAULT NOW(),
  updated_at      TIMESTAMPTZ DEFAULT NOW(),

  CONSTRAINT unique_weekly_report UNIQUE (camera_id, week_start)
);

CREATE INDEX idx_reports_camera_week ON reports(camera_id, week_start DESC);
CREATE INDEX idx_reports_status ON reports(status);
```

### 테이블: `report_ai_contents` (AI 생성 텍스트)

```sql
CREATE TABLE report_ai_contents (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  report_id       UUID NOT NULL REFERENCES reports(id) ON DELETE CASCADE,

  -- AI 분석 결과 (JSON)
  overall_comment TEXT NOT NULL,                 -- 전체 코멘트

  prompt_version  VARCHAR(20),                   -- 프롬프트 버전 (관리용)

  created_at      TIMESTAMPTZ DEFAULT NOW(),

  CONSTRAINT unique_report_ai UNIQUE (report_id)
);
```

### 테이블: `push_notifications` (알림 이력)

```sql
CREATE TABLE push_notifications (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID NOT NULL REFERENCES users(id),
  report_id   UUID REFERENCES reports(id),
  type        VARCHAR(50) NOT NULL,              -- 'WEEKLY_REPORT' | 'ALERT'
  title       VARCHAR(200) NOT NULL,
  body        TEXT NOT NULL,
  sent_at     TIMESTAMPTZ DEFAULT NOW(),
  status      VARCHAR(20) DEFAULT 'SENT',        -- SENT | FAILED | READ
  read_at     TIMESTAMPTZ
);

CREATE INDEX idx_notifications_user ON push_notifications(user_id, sent_at DESC);
```

## DynamoDB 테이블

### `momi-report-cache` (리포트 빠른 조회용)

```json
// Partition Key: cameraId (String)
// Sort Key: weekStart (String, "2026-04-09")
// TTL: 90일 자동 만료

{
  "cameraId": "CAM-A1B2C3",
  "weekStart": "2026-04-09",
  "reportId": "rep_uuid_001",
  "sleepScore": 82,
  "scoreTrend": "up",
  "weekNumber": 4,
  "status": "COMPLETED",
  "s3Key": "reports/CAM-A1B2C3/2026-04-09/report.json",
  "generatedAt": "2026-04-15T07:00:00Z",
  "ttl": 1757001600
}
```

**글로벌 보조 인덱스 (GSI):**

| GSI 이름 | Partition Key | Sort Key | 용도 |
|---------|-------------|---------|------|
| `status-index` | status | generatedAt | 생성 대기 리포트 조회 |

## 마이그레이션 (Prisma)

```prisma
// schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id           String    @id @default(uuid())
  email        String    @unique
  passwordHash String    @map("password_hash")
  name         String
  phone        String?
  createdAt    DateTime  @default(now()) @map("created_at")
  updatedAt    DateTime  @updatedAt @map("updated_at")
  deletedAt    DateTime? @map("deleted_at")

  cameras      Camera[]

  @@map("users")
}

model Camera {
  id          String    @id @default(uuid())
  userId      String    @map("user_id")
  cameraId    String    @unique @map("camera_id")
  name        String?
  isActive    Boolean   @default(true) @map("is_active")
  registeredAt DateTime @default(now()) @map("registered_at")
  lastSeenAt  DateTime? @map("last_seen_at")
  createdAt   DateTime  @default(now()) @map("created_at")

  user         User          @relation(fields: [userId], references: [id])
  babyProfile  BabyProfile?
  sleepSessions SleepSession[]
  reports      Report[]

  @@map("cameras")
}
```

## 데이터 보존 정책

| 데이터 | 보존 기간 | 이유 |
|--------|---------|------|
| 수면 세션 (raw) | 12개월 | 장기 성장 추이 분석 |
| 리포트 (DB) | 12개월 | 히스토리 조회 |
| 리포트 캐시 (DynamoDB) | 90일 (TTL) | 빠른 조회용 |
| 원본 카메라 데이터 (S3) | 6개월 | 재분석 가능성 |
| 알림 이력 | 30일 | 디버깅 |

## 로컬 개발 환경 (Docker)

```yaml
# docker-compose.yml
version: '3.8'
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: momi_db
      POSTGRES_USER: momi
      POSTGRES_PASSWORD: momi_local
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  # DynamoDB Local (선택)
  dynamodb-local:
    image: amazon/dynamodb-local
    ports:
      - "8000:8000"

volumes:
  postgres_data:
```

```bash
# 로컬 DB 실행
docker-compose up -d

# Prisma 마이그레이션 실행
npx prisma migrate dev --name init

# Prisma Studio (DB GUI)
npx prisma studio
```
