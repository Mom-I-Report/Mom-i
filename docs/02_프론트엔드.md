## 💡 서비스의 'Kick' (핵심 가치): 맞춤형 수면 교육 가이드라인

부모가 "이거 괜찮네"라고 느낄 수 있는 차별점(Kick)은 단순한 데이터 나열이 아닌, **실질적인 수면 솔루션**입니다. 주 1회 데이터 분석 생성을 통해 비용 부담이 적은 장점을 활용하여, 맞춤 분석의 역할을 극대화합니다.

### 기획 방향의 대전환
1. **단순 요약 지양:** 데이터(수면시간, 취침시간)를 단순히 텍스트로 풀어주는 요약 수준에서 벗어납니다.
2. **로우 데이터 비중 축소:** 일별 상세 테이블이나 기본 현황 등 단순 기록형 데이터는 콤팩트하게 최소한의 영역에만 기재합니다.
3. **수면 교육법 기반 가이드라인 전면 배치:**
   - 여러 검증된 수면 교육법(퍼버법(Ferber), 쉬닥법, 안눈법 등) 중, 현재 주차 데이터와 월령에 가장 적합한 교육법을 시스템이 판별하여 제안.
   - 단순 제안에 그치지 않고, 그 교육법을 당장 오늘 밤 어떻게 시도해야 하는지(How-to) 상세한 가이드라인 제공.
4. **월령별 맞춤 킥(Kick):** 해당 개월 수에 겪는 전형적인 문제(예: 원더윅스, 이앓이, 분리불안)를 짚어주는 인사이트 제공.

## 🚀 프론트엔드 개발 전략 (투트랙 방식)

백엔드 개발이 진행되는 동안 프론트엔드의 대기 시간을 최소화하고, 수면 교육 콘텐츠 중심의 UI/UX 완성도를 높이기 위해 **"더미데이터 선반영 → API 후연동" (2단계 개발)** 프로세스를 채택합니다.

> 🚨 **개발 범위 한정 (회원가입/로그인 제외)**  
> 인증(스플래시, 로그인, 회원가입) 플로우는 M-Take 측에서 진행하므로, 본 프론트엔드 앱은 철저히 **‘로그인 이후 진입하는 수면 리포트 출력 및 렌더링’** 범위에만 100% 집중합니다.

### Phase 1: Vite + TypeScript 기반 더미데이터 시뮬레이션 (현재 완료 상태)
- **Vite 개발 환경 구축 (`frontend/src`)**: 단일 `report.html`에 하드코딩되었던 로직을 체계적인 프론트엔드 프로젝트로 이식했습니다.
- **백엔드 의존성 완전 분리 (`data/mockData.ts`)**: 화면을 그리는 로직과 데이터를 완전히 분리했습니다. 현재 화면은 이 파일(`mockData.ts`)의 데이터를 `import`하여 그려집니다.

### Phase 2: 백엔드 API 연동 (백엔드 DTO 확정 시점)
- 백엔드 팀에서 JSON 응답 규격이 확정되고 API가 배포되면, 아래 작업만으로 연동이 끝납니다.
  1. `frontend/src/data/mockData.ts` 파일을 폴더째로 **완전 삭제**
  2. `main.ts` 최상단의 `import { mockData }` 구문을 지우고, `fetch('백엔드API')` 로 교체 및 Key 값 맵핑.

## 🗂 현재 프론트엔드 디렉터리 아키텍처

로컬에 생성된 프론트엔드 폴더(`c:\Mom-i\frontend`)의 주요 구조입니다.

| 파일/경로 | 설명 | 상태 |
|----------|------|------|
| `index.html` | 웹을 띄우는 최상위 껍데기. SEO 및 폰트 로드 담당 (`<div id="app">`) | 🟢 완료 |
| `src/main.ts` | **(핵심 로직)** 데이터를 불러와 HTML 템플릿(Template Literal)으로 화면을 렌더링하는 진입점 모듈 | 🟢 완료 |
| `src/style.css` | A4 리포트 레이아웃, 인쇄용 CSS(`@media print`), 디자인 토큰 등 전역 스타일 집합 | 🟢 완료 |
| `src/data/mockData.ts` | **(삭제 예정)** 백엔드가 내려줄 JSON 역할을 예행 연습하는 거대한 더미데이터 파일 | 🟢 완료 |

## 📄 신규 핵심 화면 구성 (A4 리포트)

수면 교육 가이드라인을 중심으로 레이아웃이 최적화되었습니다.

| 섹션 | 구성 요소 및 내용 | 비중 |
|------|----------------|------|
| **헤더 & 기본 정보** | Mom-i 로고, 영유아 이름 (`민준이`), 월령 (`7개월`), 주차 정보. | 낮음 |
| **이번 주 수면 현황 (요약)** | 평균 수면시간, 기상/취침시간, 실내 온도 등 단순 지표. | 낮음 |
| **일별 데이터 (가볍게)** | 일주일 데이터 테이블은 공간을 최소화하여 콤팩트하게 상단에 배치. | 낮음 |
| **✨ 맞춤 수면교육 제안** | **(메인 핵심 영역)** 이번 주 데이터와 월령을 기반으로 개인화 분석이 선택한 수면 교육법(예: 쉬닥법) 안내와 그 구체적인 실행 방법. | **가장 높음** |
| **📉 데이터 맞춤 분석 팁** | 일별 수면 데이터(예: 온도 폭증)를 기반으로 직접적인 원인과 개선 행동 촉구 코멘트. | 중간 |
| **💡 월령별 케어 킥 (Kick)**| 지금 시기의 아이 부모들이 겪는 수면 저해 요소(원더윅스 등)와 대처 방안. | **높음** |
| **광고 배너 & 푸터** | 관련 타겟 육아용품 광고 배너, 카피라이트 및 경고 문구. | 낮음 |
