# 🖥️ Mom-i 프론트엔드 스펙
> 최종 수정: 2026.04.16

---

## 기술 스택

| 항목 | 선택 | 이유 |
|------|------|------|
| **빌드 도구** | Vite 8 | 빠른 HMR, 경량 번들 |
| **언어** | TypeScript | 타입 안정성 |
| **스타일** | Vanilla CSS | 외부 의존성 제거, 완전한 커스텀 |
| **폰트** | Noto Sans KR + Outfit | 한국어 최적화 + 숫자 가독성 |
| **라우팅** | Hash-based SPA | 서버 설정 불필요 |
| **차트** | SVG 직접 구현 | 라이브러리 없이 경량화 |
| **상태 관리** | 없음 (단순 렌더링) | MVP 단계에서 불필요 |

## UI/UX 설계 원칙

### 타겟 사용자
> **20~35세 영유아를 둔 어머니** · 스마트폰 친화적 · 빠른 정보 파악 선호

### 4가지 원칙

| 원칙 | 구현 방법 |
|------|---------|
| **전문성** | 의료/육아 앱 수준 디자인, 데이터 기반 수치 강조 |
| **직관성** | 핵심 정보 한 화면에, 스크롤 최소화 |
| **공감성** | 아이 중심 따뜻한 톤, 이모지 적극 활용 |
| **신뢰성** | AI 출처 명시, KPI 기반 점수 표시 |

## 백엔드 연동 계획 (API 연동 시)

현재 `mockData.ts`의 데이터를 아래 API로 교체 예정:

```typescript
// api/reportsApi.ts (프로토타입)

const BASE_URL = import.meta.env.VITE_API_BASE_URL;

// 주간 리포트 목록 조회
export async function getReports(cameraId: string) {
  const res = await fetch(`${BASE_URL}/api/v1/reports?cameraId=${cameraId}`);
  return res.json();
}

// 특정 리포트 상세 조회
export async function getReport(reportId: string) {
  const res = await fetch(`${BASE_URL}/api/v1/reports/${reportId}`);
  return res.json();
}
```

> 💡 **환경변수**: `VITE_API_BASE_URL`을 `.env.local`에 설정
