## 2. 프론트엔드 환경변수화

Admin.tsx, Demo.tsx에 하드코딩되어 있던 API URL·Key를 Vite 환경변수로 분리.

| 항목 | 변경 전 | 변경 후 |
|------|--------|--------|
| API URL | `'http://localhost:8000'` 하드코딩 | `VITE_API_BASE_URL` (기본 `http://localhost:8000`) |
| API Key | `'dev-local-key'` 하드코딩 | `VITE_API_KEY` (미설정 시 빈 값, Admin UI에서 입력) |

- `frontend/.env.local` — `VITE_API_BASE_URL`, `VITE_API_KEY` 관리 (gitignore 대상)
