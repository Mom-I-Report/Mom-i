## 2. EMTAKE 릴레이 클라이언트 구현 (emtake/client.py)

- `_fetch_raw()`에 선택 파라미터 추가
  - `val`: 마지막 저장일 기준 N일 전 데이터
  - `date_str`: 특정 날짜 지정
  - `user_type`: `"LLMREPORT"` (유아) / `"LLMREPORTS"` (시니어)
- 기존 스텁(주석) 6개 전부 구현
  - `fetch_baby_info()` — 생년월일 → `baby_age_months` 계산, 개인정보 미저장
  - `fetch_sleep_daily()` — val 파라미터로 날짜별 수면 데이터 조회
  - `fetch_breath()` — Min/Max → avg 자동 계산
  - `fetch_body_temp()` — Min/Max → avg 자동 계산 (델타값)
  - `fetch_environment()` — IndoorTemp + dB 병렬 호출
  - `fetch_events()` — 울음·이탈 횟수
