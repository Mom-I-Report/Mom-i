---

## 1. 배경

맘아이는 엠테이크 스마트 카메라로부터 수집된 데이터를 기반으로 **AI 주간 수면 리포트**를 생성합니다.
현재 기본 수면 데이터 연동은 완료된 상태이며, 리포트 품질 향상을 위해 아래 두 가지를 협의하고자 합니다.

1. **현재 수신 중인 데이터 항목 확인** — 양측이 동일한 이해를 가지고 있는지 검증
2. **추가 데이터 항목 요청** — 리포트 신규 기능 구현에 필요한 데이터

---

## 2. 현재 수신 중인 데이터 (확인 요청)

아래 항목들은 맘아이 서버가 현재 엠테이크로부터 수신 중인 것으로 파악하고 있습니다.
각 항목이 실제 전송되고 있는지 확인 부탁드립니다.

### 2-1. 수면 데이터 (`CMD: SleepData`)

| 필드 | 설명 | 현재 수신 단위 | 맘아이 변환 단위 |
|------|------|--------------|----------------|
| `day_gs` | 일별 실제 수면 시간 | 문자열 (`"9h30m"`) | 분 정수 (`570`) |
| `day_pr` | 일별 뒤척임 시간 | 문자열 (`"0h25m"`) | 분 정수 (`25`) |
| `month_gs` | 월간 평균 수면 시간 | 문자열 (`"9h15m"`) | 시간 소수 (`9.25`) |
| `month_pr` | 월간 평균 뒤척임 시간 | 문자열 (`"0h30m"`) | 시간 소수 (`0.5`) |

> 문자열 → 숫자 변환은 맘아이 서버에서 처리합니다. 포맷 변경 시 사전 공유 부탁드립니다.

---

### 2-2. 실내 환경 데이터 (`CMD: IndoorTemp`, `CMD: dB`)

| 필드 | 설명 | 단위 |
|------|------|------|
| `temp_avg` | 수면 중 평균 실내 온도 | °C |
| `temp_max` | 수면 중 최고 실내 온도 | °C |
| `temp_min` | 수면 중 최저 실내 온도 | °C |
| `db_avg` | 수면 중 평균 소음 | dB |
| `db_max` | 수면 중 최대 소음 | dB |

---

### 2-3. 호흡수 데이터 (`CMD: Breath`)

| 필드 | 설명 | 단위 |
|------|------|------|
| `breath_min` | 수면 중 최소 호흡수 | 회/분 (정수) |
| `breath_max` | 수면 중 최대 호흡수 | 회/분 (정수) |
| `breath_avg` | 수면 중 평균 호흡수 | 회/분 (정수) |

> 활용 용도: AI가 미국 소아과학회(AAP) 기준 월령별 정상 범위와 비교해 이상 여부를 판정합니다.
> 정상 범위 예시 — 생후 6~12개월: 20~40회/분

---

### 2-4. 체온 데이터 (`CMD: Temp`)

| 필드 | 설명 | 단위 |
|------|------|------|
| `body_temp_min` | 수면 중 최저 체온 | °C (소수점 1자리) |
| `body_temp_max` | 수면 중 최고 체온 | °C (소수점 1자리) |
| `body_temp_avg` | 수면 중 평균 체온 | °C (소수점 1자리) |

> 활용 용도: 최고 체온 기준 상태 판정 (37.4°C 이하: 정상 / 37.5~37.9°C: 미열 주의 / 38.0°C 이상: 발열 의심)

## 3. 추가 데이터 요청

아래 항목은 현재 수신되지 않고 있으나, 리포트 신규 기능 구현을 위해 필요합니다.

### [요청 1] 취침 시각 / 기상 시각 — **우선순위 높음**

**요청 이유:**
리포트 UI에 일별 취침·기상 시각을 표시하는 기능을 추가할 예정입니다.
현재는 수면 시간(분)만 수신하고 있어 몇 시에 잠들고 몇 시에 일어났는지 표시가 불가합니다.

**요청 항목:**

| 필드명 (제안) | 설명 | 단위 | 예시 |
|-------------|------|------|------|
| `sleep_start_time` | 취침 시각 | `HH:MM` 문자열 | `"21:30"` |
| `wake_time` | 기상 시각 | `HH:MM` 문자열 | `"06:45"` |

**적용 화면 예시:**

```
날짜    취침     기상     수면시간   점수
월 4/9  21:30   06:45   13h 15m    78
화 4/10 21:00   06:30   12h 00m    88
수 4/11 22:00   06:30   11h 30m    62   ← 늦은 취침 + 뒤척임 많음
```

**질의 사항:**
- 현재 기기에서 취침·기상 시각을 측정/기록하고 있나요?
- 가능하다면 어떤 형식으로 전송이 가능한지 알려주세요.
- 불가능하다면 해당 UI 요소를 제거하는 방향으로 조정할 예정입니다.

---

### [요청 2] 일별 호흡수 / 체온 데이터 — **우선순위 중간**

**현재 수신 형태:** 주간 집계값 1세트 (min/max/avg)
**요청 형태:** 날짜별 집계값 (7일치)

**요청 이유:**
현재 호흡수·체온은 주 단위로만 수신해 일별 차이를 파악할 수 없습니다.
특정 날 발열이 있었는지, 특정 날 호흡이 불규칙했는지 일별로 표시하면 리포트 정확도가 높아집니다.

**요청 항목:**

```json
"breath_daily": [
  { "date": "2026-04-14", "breath_min": 22, "breath_max": 35, "breath_avg": 27 },
  { "date": "2026-04-15", "breath_min": 20, "breath_max": 40, "breath_avg": 30 },
  ...
],
"body_temp_daily": [
  { "date": "2026-04-14", "body_temp_min": 36.3, "body_temp_max": 36.8, "body_temp_avg": 36.5 },
  { "date": "2026-04-15", "body_temp_min": 36.5, "body_temp_max": 37.6, "body_temp_avg": 37.0 },
  ...
]
```

**질의 사항:**
- 일별 호흡수·체온 집계값 전송이 기술적으로 가능한가요?
- 가능하다면 현재 주간 집계 필드(`breath_min` 등)와 병행 전송 또는 교체 중 어느 방식이 선호되나요?

## 4. 데이터 전송 주기 확인

현재 맘아이가 이해하고 있는 전송 주기가 맞는지 확인 부탁드립니다.

| 데이터 | 전송 주기 | 집계 기간 |
|--------|-----------|-----------|
| SleepData (day_gs, day_pr) | 매일 | 전날 수면 |
| SleepData (month_gs, month_pr) | 매일 | 이번 달 누계 |
| IndoorTemp, dB | 실시간 또는 주기적 | 수면 구간 |
| Breath (호흡수) | ? | ? |
| Temp (체온) | ? | ? |

> Breath, Temp의 전송 주기와 집계 기간을 명확히 알려주시면 리포트 생성 로직에 반영하겠습니다.

## 5. 현재 리포트 서버 처리 흐름 (참고)

엠테이크에서 전달받은 데이터가 어떻게 활용되는지 공유드립니다.

```
엠테이크 기기
    │
    │ (SleepData, IndoorTemp, dB, Breath, Temp)
    ▼
맘아이 서버  ─── 데이터 수집 및 가공 ───►  리포트 서버
                                              │
                                              │ 1. 원본 데이터 저장 (3주 보관)
                                              │ 2. 호흡수 · 체온 정상 여부 자동 판정
                                              │ 3. 전주 대비 트렌드 계산
                                              │ 4. Gemini AI 리포트 생성 (5개 섹션)
                                              │
                                              ▼
                                         맘아이 앱 (사용자)
                                              │
                                              │ 주간 수면 리포트 표시
                                              │ - 수면 점수
                                              │ - 일별 타임라인
                                              │ - 호흡 · 체온 분석 카드
                                              │ - AI 케어 팁
```
