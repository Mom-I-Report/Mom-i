# 1. 수면 데이터 연동 관련

### 전달 데이터 항목

릴레이 서버에서 아래 수면 데이터를 전달받는 방향으로 논의됨.

- 깨어있음
- 깊은 수면
- 렘수면
- 얕은 수면
- 깬 시간
- 잔 시간

추후 시니어 대상 데이터 확장 가능성까지 고려하여,

현재 단계부터 **여유 있는 데이터 파싱 구조**로 설계 필요.

### 데이터 구분 방식

- 유아 데이터 / 시니어 데이터는 코드값으로 구분 가능하도록 구성되어 있다고 전달받음.
- 우리 서버는 우선적으로 **유아 데이터 위주로만 수신 가능하도록 적용 예정**.

### 데이터 처리 방식

기존처럼 일별 데이터를 우리 서버에서 평균 계산하는 방식이 아니라,

→ 릴레이 서버 측에서

**주간 평균 데이터를 계산 후 일괄 전달하는 구조**로 진행 예정.

---

## 2. 테스트 계정 및 데이터 제공

- 기존 엑셀 파일 기준 약 17개 계정 데이터 존재.
- 데이터는 매일 랜덤 형태로 제공됨.
- 업데이트 시간:
    - 매일 00:00 ~ 01:00 까지 랜덤데이터 업데이트

### 추가 요청 사항

- 17개 계정을 0~30개월 구간에 적절히 분배하여 세팅해주신다 했음

---

## 3. 리포트 제공 방식

리포트 제공 관련하여 PDF / HTML 방식 논의 진행.

현재 우리 작업물에 PDF 생성 시스템이 어느 정도 구축되어 있어

우선적으로 **PDF 방식 적용 방향**으로 의견 정리됨.

다만 최종 결정은 책임님과 추가 논의 예정.

---

## 4. 쉐어리스트(공유 시스템)

기존:

- 리포트가 주변인에게 자동 전달되는 방식 검토

변경:

- 공유 리스트 내에서 **사용자가 직접 전달 대상 선택 후 공유하는 방식**으로 결정됨.

해당 부분은 구독 과정에서 리포트를 받고 싶은 사람의 연락처(이메일 or 핸드폰 번호)를 함께 등록하면 정기적으로 해당 연락처에 문자 발송 보냄. → 5번과 이어지는 내용입니다. 

---

## 5. 부모 대상 메시지 기능

리포트 전달 시 단순 리포트만 보내는 것이 아니라,

- 메시지 형태의
- 한 줄 칭찬/응원 코멘트가 함께 전달되도록 기능 추가 요청받음.

예시:

- “오늘도 아이와 함께 좋은 하루 보내셨네요 😊”
- “우리 아이가 건강하게 성장하고 있어요!”

## 6. AI 기반 아이 사진 활용 기능 (추후 계획)

아이 사진 데이터를 활용하여,

- 성장 과정에 따라
- AI 기반으로
- 매 리포트마다 다른 분위기/순간의 이미지가 포함되도록 하는 기능 논의됨.

※ 현재 즉시 적용 기능은 아니며, 추후 확장 계획으로 검토 중.
