## 1. EMTAKE 릴레이 데이터 전체 통합

릴레이 서버에서 수신 가능한 모든 필드를 리포트에 반영

### 스키마 확장 (schemas.py)

| 추가 항목 | 내용 |
|----------|------|
| `SleepSession` 모델 신규 | start, end, duration_min, wake_up, is_nap |
| `SleepDay` 확장 | wakeup_count, device_status, sessions 추가 |
| `EnvironmentData` 확장 | humidity_min/max/avg, bright_min/max/avg 추가 |
| `MonthlySummary` 확장 | week_sleep_h, week_restless_h 추가 (week_gs/pr) |
| `ReportSummary` 확장 | week_sleep_h, week_restless_h, humidity_avg, bright_avg, nap_count 추가 |

### EMTAKE 클라이언트 확장 (emtake/client.py)

- `_parse_wakeup_count(s)`: "5 times" → 5 파싱
- `_classify_sessions(sessions)`: start 시각 21:00 미만이면 `is_nap=True`
- `parse_sensor_data_day()`: Humidity, Bright, sessions, status, week_gs/pr, day_wakeup 파싱 추가
- `build_generate_request_from_sensor()`: 새 필드 조건부 포함

### 리포트 서비스 확장 (report_service.py)

- `_build_summary()`: sessions에서 nap_count 집계
- `_build_pattern_summary()`: 습도(40%/60% 기준), 낮잠 패턴 추가
- `_build_ai_context()`: this_week에 humidity/bright/week 평균/nap_count 추가, daily에 wakeup_count/device_status/nap_sessions/night_sessions 추가

### Gemini 프롬프트 강화 (gemini_client.py)

- 월령을 "7개월 (약 30주령)" 형식으로 변환해 전달
- 실내 온도 판정: 18~22°C (신생아 20~22°C) 기준 ✅/⚠ 표기
- `_bedtime_note()`: 야간 수면 평균 시작시각 계산 → 월령별 권장 취침시간 비교
- dB: "소음 최고 XdB (릴레이 Max값만 제공)"으로 변경 (중복 표시 제거)
- 조도 >20lux이면 "⚠ 수면 중 밝음 (5lux 이하 권장)" 표기
- 습도 <40% / >60% 경고 표기
- Daily 줄에 wakeup_count, 낮잠 수, 첫 야간 수면 시작~종료, device_status 추가

### 도메인 지식 보강 (knowledge.md)

| 추가 항목 | 기준 |
|----------|------|
| 권장 습도 | 40~60%, 이탈 시 건조/과습 언급 |
| 수면 중 조도 | 5lux 이하 권장, 낮잠 20lux 이하 |
| 소음 | 최고 60dB 이상이면 수면 분절 가능성 명시 |
| 실내 온도 | 최저 15°C 미만 / 최고 24°C 초과 시 점검 권장 |

## 2. 프론트엔드 React/Vite 전환 및 개선

### ReportView.tsx (공용 컴포넌트)

- `hideSideAds` prop 추가: 모바일 뷰에서 양옆 광고 제거
- `mode="split"` PC 보기: `ResizeObserver`로 컨테이너 너비 감지 → 720px 미만이면 1컬럼 자동 전환 (반응형)
- `meta.name` 필드 추가

### Demo.tsx (테스트 페이지)

- 초기 상태 완전 비움 (예시 더미 데이터 전면 제거)
- 리포트 생성 중 로딩 스피너 표시 (이전 리포트 대신)
- 생성된 리포트 없을 때 안내 문구 표시
- JSON 파일 업로드 시 자동 파싱 (EMTAKE relay SensorData 형식)
- PDF 다운로드: A4 고정 크기 → 캡처 비율 기반 동적 크기 (여백 제거)
- 환경 카드에 습도(최저/최고), 조도(lux, 최저/최고) 입력 필드 추가
- 시작일 초기값을 이번 주 월요일로 자동 설정

## 3. 버그 수정

| 버그 | 파일 | 수정 내용 |
|------|------|---------|
| CORS `allow_credentials=True` + `allow_origins=["*"]` 조합 (spec 위반) | `main.py` | `allow_credentials=False`로 변경 (Bearer JWT 사용, 쿠키 불필요) |
| `body_temp` 더미 데이터가 절대 체온값으로 생성됨 | `simulator_service.py` | delta값(0.0~1.5°C) 범위로 수정 |
| `db_avg`가 `db_max`와 독립적으로 생성됨 | `simulator_service.py` | `db_avg = db_max` 통일 (릴레이는 Max만 제공) |
| 모바일 뷰에서 광고 없을 때 레이아웃 깨짐 | `ReportView.tsx` | `hideSideAds=true`이면 `side-ad-container` 클래스 제거 |
| 테스트 페이지 레이블 `{월령}` JSX 오류 | `Demo.tsx` | `DEMO-[월령]m`으로 수정 |
