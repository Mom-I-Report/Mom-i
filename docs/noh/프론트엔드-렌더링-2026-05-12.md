## ReportView.tsx

Demo.tsx / Admin.tsx 모두 `<ReportView data={...} mode={...} />` 형태로 사용.

| props | 타입 | 기본값 | 설명 |
|-------|------|--------|------|
| `data` | `any` | (필수) | API 응답 (GenerateReportResponse) |
| `mode` | `'default' \| 'split'` | `'default'` | 레이아웃 모드 — `split`은 PC 2단 분할 |
| `hideSideAds` | `boolean` | `false` | 사이드 광고 숨김 (PDF 캡처 시 사용) |
| `contentMaxWidth` | `number` | — | 컨텐츠 최대 너비(px) 제한 |
| `meta` | `{ name?, ageMonths?, weekNum?, weekStart?, weekEnd?, generated? }` | — | 리포트 메타 정보 (헤더 표시용) |

**반응형**: Demo.tsx에서 ResizeObserver로 뷰포트 너비 720px 기준 자동 전환 (`mode='default'` ↔ `'split'`).

렌더링 섹션 순서:
1. 주간 요약 (`avg_sleep_h`, `avg_restless_min`, `cry_count`, `nap_count`, `body_temp`, `breath`)
2. 실내 환경 (`temp_avg`, `db_max`, `humidity_avg`, `bright_avg`)
3. 일별 수면 차트 (`daily`)
4. 트렌드 뱃지 (`trend` — 전주 대비 차이, 없으면 미표시)
5. AI 솔루션 (`sleep_guide` + `kick_action`)
6. AI 코멘트 (`ai_comment` 카드 목록)
7. 월령 키워드 (`age_kick`)
8. 부모 응원 메시지 (`parent_message`)

## Demo.tsx

접속: `http://localhost:5173/demo.html`

- ser_no, 월령, 수면 데이터 입력 → `POST /api/v1/reports/generate` 직접 호출
- `html2canvas` + `jsPDF`로 리포트 PDF 다운로드 (광고 링크 클릭 영역 포함)
- `MOCK_SLEEP`: 7일치 기본값 배열 (`SleepEntry` 타입, `sessions` / `wakeup_count` / `device_status` null 초기화)
- 뷰 모드 토글 버튼 (모바일 ↔ PC) + ResizeObserver 자동 전환 (`mode='default'` ↔ `'split'`)
- API endpoint: `VITE_API_BASE_URL` 환경변수 (기본 `http://localhost:8000`)
- API Key: `VITE_API_KEY` 환경변수 (기본 `dev-local-key`)

## Admin.tsx

접속: `http://localhost:5173/admin.html`

- X-API-Key 헤더 입력 (UI 상단, `VITE_API_KEY` 환경변수로 초기값 설정 가능)
- API endpoint: `VITE_API_BASE_URL` 환경변수 (기본 `http://localhost:8000`)
- `GET /api/v1/admin/devices` 기기 목록 조회 → 기기 클릭 → `GET /api/v1/admin/devices/{ser_no}/reports` 최근 3주치 조회
- 주차별 탭 전환 + `ReportView`로 리포트 렌더링
- 뷰 모드 토글 (모바일/PC) + `html2canvas`+`jsPDF` PDF 다운로드 (Demo.tsx와 동일 구조)

## 이전 방식과의 차이점

| 항목 | 04-27 (구) | 05-12 (현재) |
|------|-----------|-------------|
| 렌더링 방식 | `report-renderer.js` (vanilla JS) | `ReportView.tsx` (React 컴포넌트) |
| 스타일 | `report.css` (공유 CSS 파일) | CSS-in-JS (inline style) |
| 진입점 | `demo.html`, `admin.html` (정적 HTML) | `main-demo.tsx`, `main-admin.tsx` |
| 렌더링 옵션 | `opts.showTrend`, `opts.radarId` 등 | props (`data`, `mode`, `hideSideAds`, `meta`) |
| 반응형 | 없음 | ResizeObserver (720px 분기, `mode` prop 연동) |
| PDF 캡처 | 없음 | `html2canvas`+`jsPDF` (Demo.tsx, Admin.tsx 모두 지원) |
| 광고 링크 | - | PDF 내 `pdf.link()` 클릭 영역 오버레이 (AdBanner `data-ad-link`) |
| 광고 이미지 | 외부 URL | `frontend/public/` 로컬 파일 (CORS 없이 PDF 렌더링) |
