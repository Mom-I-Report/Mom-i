## ReportView.tsx

Demo.tsx / Admin.tsx 모두 `<ReportView reportData={...} viewMode={...} />` 형태로 사용.

| props | 타입 | 설명 |
|-------|------|------|
| `reportData` | `any` | API 응답 (GenerateReportResponse) |
| `viewMode` | `'mobile' \| 'pc'` | 렌더링 레이아웃 모드 |

**반응형**: ResizeObserver 기반으로 뷰포트 너비 720px 기준 `mobile`/`pc` 자동 전환 (Demo.tsx에서 제어).

렌더링 섹션 순서:
1. 주간 요약 (`avg_sleep_h`, `avg_restless_min`, `cry_count`, `nap_count`, `body_temp`, `breath`)
2. 실내 환경 (`temp_avg`, `db_max`, `humidity_avg`, `bright_avg`)
3. 일별 수면 차트 (`daily`)
4. 트렌드 뱃지 (`trend` — 전주 대비 차이, 없으면 미표시)
5. AI 솔루션 (`sleep_guide` + `kick_action`)
6. AI 코멘트 (`ai_comment` 카드 목록)
7. 월령 키워드 (`age_kick`)
8. 부모 응원 메시지 (`parent_message`)

## Demo.tsx

접속: `http://localhost:5173/demo.html`

- ser_no, 생년월일, 수면 데이터 입력 → `POST /api/v1/reports/generate` 직접 호출
- `html2canvas`로 리포트 PDF 캡처 기능 포함
- `EMPTY_SLEEP`: 7일치 기본값 배열 (`sessions` / `wakeup_count` / `device_status` null 초기화)
- viewMode 토글 버튼 (mobile ↔ pc) + ResizeObserver 자동 전환

---

## Admin.tsx

접속: `http://localhost:5173/admin.html`

- X-API-Key 입력 → `GET /api/v1/admin/devices` 기기 목록 조회
- 기기 클릭 → `GET /api/v1/admin/devices/{ser_no}/reports` 최근 3주치 조회
- 주차별 탭 전환 + `ReportView`로 리포트 렌더링
