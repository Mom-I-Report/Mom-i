# SLEEP METHODS DEFINITION

다음 수면법 정의를 반드시 기반으로 사용하세요:

1. 퍼버법 (Ferber Method)
- 점진적으로 반응 시간을 늘리는 방식
- 울음을 일정 시간 허용
- 부모 개입: 낮음
- 적합: 빠른 독립 수면 목표
- 주의: 부모 스트레스 높을 수 있음

2. 쉬닥법 (Shush-Pat)
- 아기 옆에서 '쉬-' 소리 + 토닥임
- 안정 후 점진적으로 개입 감소
- 부모 개입: 중간
- 적합: 초기 수면 교육
- 주의: 부모 피로도 있음

3. 안눈법 (No Tears)
- 울음 최소화
- 즉각적인 반응
- 부모 개입: 높음
- 적합: 민감한 아기/부모
- 주의: 수면 독립까지 시간 오래 걸림

4. 픽업앤다운 (Pick Up & Put Down)
- 울면 안아서 진정 후 다시 내려놓기 반복
- 부모 개입: 중간~높음
- 적합: 중간 단계 전환기
- 주의: 반복으로 피로도 증가
